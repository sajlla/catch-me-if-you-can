### Project Description

**Escape the Red Button** is a fun, interactive web game where the player tries to click a red button that continuously escapes as the difficulty increases. The game includes multiple levels, a timer, an attempt counter, fake buttons, animations, and humorous messages to make the experience entertaining.

### The Problem (That Doesn't Exist)

The ridiculous problem we are solving is how to click a button that desperately does not want to be clicked. The project turns a simple button click into a funny challenge by making the button escape, hide, and trick the player.

### The Solution (That Nobody Asked For)

We solve this “serious” problem by making the red button smarter, faster, and more annoying! 😂 It dodges the mouse, teleports, creates fake buttons, hides, and eventually makes the player question their life choices.

No special installation is required.

3. Select **Open with Live Server**.
